# اتصال wifi

تطبيق أندرويد للمكالمات الصوتية والمراسلة عبر الشبكة المحلية (Wi-Fi / LAN) بتشفير طرف لطرف، مبني بلغة Kotlin و Jetpack Compose بتصميم Material 3 وواجهة عربية كاملة (RTL).

**تطوير:** م/ عبدالرزاق عزي

---

## المميزات الرئيسية

- **تشفير طرف لطرف (E2EE):** تبادل مفاتيح `ECDH (secp256r1)` واشتقاق مفاتيح الجلسة عبر `HKDF-SHA256` وتشفير الرسائل والملفات والصوت بـ `AES-256-GCM`.
- **مراقبة الشبكة المحلية (`NetworkMonitorService`):** اكتشاف الأجهزة المتصلة تلقائياً عبر `mDNS / NsdManager` وبث `UDP` مع تحديث فوري للحالة (`متصل` / `مشغول في مكالمة` / `غير متصل`).
- **مكالمات صوتية مشفرة:** اتصال صوتي مباشر عبر `UDP` (`PCM-16`) مع عزل الضوضاء والصدى وحالة "مشغول" عند وجود مكالمة نشطة.
- **مراسلة محلية متكاملة:** رسائل نصية، صور، ملفات، رسائل صوتية، ردود، تفاعلات، رسائل ذاتية الاختفاء، وقفل التطبيق برمز PIN.
- **دعم التحقق من الأمان:** بصمة أمان مرئية وبصمة سداسية للتحقق بين الأطراف، وزر رجوع وخروج من التطبيق.

## البناء والتشغيل (Build & Test)

المشروع يستخدم **Gradle 9.3.1** و **JDK 21** (`compileSdk = 36`, `minSdk = 24`).

1. فك تشفير مفتاح التوقيع التجريبي:
   ```bash
   base64 -d debug.keystore.base64 > debug.keystore
   ```
2. تشغيل الاختبارات المحلية (Unit + Robolectric):
   ```bash
   gradle :app:testDebugUnitTest
   ```
3. بناء حزمة التثبيت (Debug APK):
   ```bash
   gradle :app:assembleDebug
   ```

> **ملاحظة:** لا ترفع ملفات `.env` أو `my-upload-key.jks` أو `debug.keystore` إلى المستودع؛ فهي مستبعدة تلقائياً في `.gitignore`.

## التكامل المستمر (GitHub Actions)

يتضمن المستودع ملف التشغيل التلقائي [`.github/workflows/main.yml`](.github/workflows/main.yml) الذي يقوم عند كل رفع (`push`) أو طلب دمج (`pull_request`) على فرع `main` / `master` بما يلي:
- تجهيز بيئة JDK 21 و Gradle 9.3.1.
- فك تشفير `debug.keystore` تلقائياً من `debug.keystore.base64`.
- تشغيل اختبارات `:app:testDebugUnitTest`.
- بناء ملف `APK` وتوفيره للتحميل المباشر من تبويب **Actions -> Artifacts** باسم `hisn-wifi-debug-apk`.
